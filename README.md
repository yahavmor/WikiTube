# WikiTube

Search once and get YouTube videos and Wikipedia results side by side.

**Live demo:** https://yahavmor.github.io/WikiTube/

<img width="1650" height="915" alt="WikiTube screenshot" src="https://github.com/user-attachments/assets/3421dffd-0199-455a-a6a7-f3934308ee09" />

## Features

- One search runs against the YouTube Data API and the Wikipedia API
- Play any result in the embedded player
- Search history saved in localStorage, with a confirmation before clearing it
- Results cached for repeated searches
- Theme switcher

## Tech

HTML, CSS, vanilla JavaScript, YouTube Data API v3 and the Wikipedia (MediaWiki) API.

## Run locally

Open `index.html` in a browser.
